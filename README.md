# OneTapService 🛠️📱

> **Capstone Project** > A full-stack on-demand service booking platform designed to connect users with local service providers effortlessly with a single tap.

---

## 📌 About the Project

**OneTapService** simplifies how users discover, schedule, and book daily household or professional services (such as plumbing, electrical work, cleaning, or repairs). Built as a modern cross-platform solution, it aims to bridge the gap between service seekers and qualified service providers with an intuitive user experience.

---

## ✨ Key Features

* 📱 **Customer Dashboard:** Seamless service selection, category browsing, and booking overview.
* 🛠️ **Service Provider Integration:** Tools for service professionals to manage incoming requests and schedules.
* 🔐 **User Authentication & Profiles:** Secure login and user account management for both customers and service providers.
* 📍 **Location-Based Service Matching:** Easily find local service providers near you.
* 📊 **Booking Tracker:** Track active, completed, and pending service requests.

---

## 🛠️ Tech Stack

* **Frontend:** [Flutter](https://flutter.dev/) / [Dart](https://dart.dev/) (Cross-platform Android & iOS app)
* **Backend:** [Node.js](https://nodejs.org/) / JavaScript
* **Database & APIs:** RESTful Web Services

🚀 Getting Started
Follow these steps to set up and run the project locally.

Prerequisites
Flutter SDK installed on your system.

Node.js (v16+) and npm installed.

An editor such as VS Code or Android Studio.

💻 Installation & Setup
1. Clone the Repository
Bash
git clone [https://github.com/Uma-Karthik/OneTapService.git](https://github.com/Uma-Karthik/OneTapService.git)
cd OneTapService

2. Backend Setup
'''
Bash
cd "BE Onetap Services" -
npm install
npm start

3. Frontend Setup
'''
Bash
cd "../FE Onetap Services" -
flutter pub get
flutter run
